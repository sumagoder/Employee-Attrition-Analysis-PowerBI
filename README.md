# Employee-Attrition-Analysis-PowerBI
Analyzed IBM HR Attrition dataset of 1,470 employees  to identify key attrition drivers using Power BI.  Built an interactive dashboard with KPI cards, slicers  and 6 chart visuals using DAX measures and Power Query.  Tools: Power BI | DAX | Power Query Dataset: IBM HR Attrition (Kaggle) Attrition Rate: 16.12% | Total Employees: 1,470
